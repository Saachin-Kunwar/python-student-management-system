# 🚀 Features
- 🎓 Add, Update, Delete student records
- 📊 Card-based Dashboard (Total Students & Courses)
- 📚 Course management system
- 🗂️ JSON-based data storage (lightweight database)
- 📅 Attendance tracking (Present / Absent)
- 📈 Automatic attendance percentage calculation
- 📝 Monthly attendance report generator
- 🔍 Interactive table (Treeview UI)
- 🧼 Clear form & input validation
- 🎯 Clean and responsive UI layout

# 🛠️ Tech Stack
- Language: Python 🐍
- GUI Library: Tkinter
- Data Storage: JSON
- Concepts Used:
Object-Oriented Programming (OOP principles)
  - Event-driven programming
  - File handling (CRUD operations)
  - GUI state management
  - Data validation
 
  # 📌 Project Details
<details> <summary>🎮 How It Works</summary>
- Add student details (Name, Age, Course) <br>
- Data is stored in a local JSON file <br>
- Select a student to update or delete  <br>
- Mark attendance daily (Present / Absent) <br> 
- System automatically calculates attendance % <br>
- Generate monthly reports using date filter <br>
</details>
